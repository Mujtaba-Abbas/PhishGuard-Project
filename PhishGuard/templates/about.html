ABOUT THE PROJECT

Making phishing risks easier to understand.

PhishGuard is a web-based phishing detection and security awareness system developed as a Web Technologies academic project.

✓

Our purpose

Phishing can trick users into visiting fraudulent websites or sharing sensitive information. PhishGuard aims to make common warning signs easier to identify by providing a simple interface, understandable risk assessments, and practical recommendations.

How detection works

The initial system uses rule-based checks. URL and email indicators contribute points to a risk score, which is mapped to one of five threat levels: Safe, Low, Medium, High, or Critical.
